# Desafio 02 - Controle de Estoque

## Objetivo

Permitir movimentações de entrada e saída de produtos em estoque.

## Regras

Cada movimentação deve conter:

- Identificador único
- Tipo da movimentação
- Descrição
- Quantidade movimentada
- Estoque anterior
- Estoque final

## Funcionalidades

✅ Entrada de estoque

✅ Saída de estoque

✅ Validação de saldo

✅ Identificador único

✅ Retorno do saldo atualizado

## Execução

```bash
node index.js
```
