# Desafio 03 - Cálculo de Juros

## Objetivo

Calcular o valor atualizado de um título vencido.

## Regra de Negócio

- Multa diária de 2,5%
- Juros simples
- Incidência apenas após o vencimento

## Parâmetros

- Valor original
- Data de vencimento

## Retorno

- Dias em atraso
- Valor dos juros
- Valor atualizado

## Execução

```bash
node index.js
```
